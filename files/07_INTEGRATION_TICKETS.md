# Epic 9 — Frontend & Backend Integration

This epic covers the steps to replace the frontend's mock data services with actual network requests to the FastAPI backend, achieving a fully working end-to-end application.

### T-15: Configure Base API Client
**Description:** Point the frontend API client to the real backend URL and handle CORS/networking.
**Acceptance Criteria:**
- `frontend/src/services/api.ts` is updated with `API_BASE_URL = 'http://localhost:8000'`.
- Shared `fetch` wrapper or Axios instance is created with proper error handling to catch network failures (like 500 errors or backend offline).

### T-16: Implement File Upload & Session Creation
**Description:** Replace the mock `createSession` function so it uploads real files to the backend.
**Acceptance Criteria:**
- `sessionApi.createSession` in `sessionApi.ts` is rewritten.
- Uses `FormData` to append the selected files.
- Makes a `POST /sessions` request to the backend.
- Successfully receives and stores the real `session_id` returned by the backend.

### T-17: Implement Pipeline Orchestration & Polling
**Description:** Trigger the NLP pipeline and poll the backend for live status updates.
**Acceptance Criteria:**
- `sessionApi.triggerPipeline` makes a `POST /sessions/{session_id}/process` request.
- `sessionApi.getPipelineStatus` is rewritten to make a `GET /sessions/{session_id}/status` request.
- The React hooks (e.g., `usePipelineStatus`) successfully poll the backend every few seconds and update the UI progress bar as the backend moves from `ingestion` to `faithfulness`.

### T-18: Implement Notes & Faithfulness Retrieval
**Description:** Fetch the finalized synthesis data from the backend once processing is complete.
**Acceptance Criteria:**
- `notesApi.getNotes` makes a `GET /sessions/{session_id}/notes` request.
- The backend's JSON response (`detailed_explanation`, `revision_notes`, and `faithfulness_report`) is correctly mapped to the frontend's TypeScript interfaces.
- The UI properly renders the generated bullet points, detailed paragraphs, and flagged hallucinations based on the real NLI scores.

### T-19: Implement Quiz Generation & Retrieval
**Description:** Connect the quiz UI to the backend's quiz generation endpoints.
**Acceptance Criteria:**
- `quizApi.generateQuiz` makes a `POST /sessions/{session_id}/quiz` request.
- `quizApi.getQuiz` makes a `GET /sessions/{session_id}/quiz` request.
- The UI correctly displays the multiple-choice, short-answer, and fill-in-the-blank questions generated by the LLM.

### T-20: End-to-End Integration Testing
**Description:** Perform a final manual walkthrough using the browser.
**Acceptance Criteria:**
- A real PDF/TXT file is uploaded via the browser UI.
- The pipeline completes without crashing.
- The frontend correctly transitions between the Upload -> Processing -> Notes Dashboard screens.
- All dynamic data reflects the actual uploaded file's content.
