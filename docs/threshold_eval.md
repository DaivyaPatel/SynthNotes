# Terminology Normalization Threshold Evaluation

## Overview
As part of Epic 2, we evaluated the default similarity threshold (`0.75`) used by our `terminology.py` clustering module. The clustering relies on embeddings generated by `sentence-transformers` (`all-MiniLM-L6-v2`) and cosine similarity to map synonymous terms across sources to a single canonical term.

We curated a labeled test set of 22 domain-specific term pairs (Machine Learning/AI context) to empirically evaluate the precision and recall of the clustering at thresholds `0.70`, `0.75`, and `0.80`.

## Methodology
- **Model:** `all-MiniLM-L6-v2`
- **Metric:** Cosine Similarity
- **Dataset:** 22 term pairs (11 true synonyms/related terms, 11 distinct/unrelated terms).

## Results

### Raw Similarity Scores (Sample)
**True Synonyms (Should Cluster):**
- Neural Network / Artificial Neural Network: `0.884` (Clusters successfully)
- Backpropagation / Backward Propagation: `0.604` (Fails to cluster at 0.75)
- Gradient Descent / Steepest Descent: `0.575` (Fails to cluster at 0.75)
- Learning Rate / Step Size: `0.105` (Fails to cluster)

**Distinct Terms (Should Not Cluster):**
- Overfitting / Underfitting: `0.886` (Falsely clusters! Antonyms share similar embedding space)
- Epoch / Batch Size: `0.297` (Successfully avoids clustering)

### Threshold Performance
| Threshold | Precision | Recall | F1 Score |
|-----------|-----------|--------|----------|
| **0.70**  | 0.50      | 0.10   | 0.17     |
| **0.75**  | 0.50      | 0.10   | 0.17     |
| **0.80**  | 0.50      | 0.10   | 0.17     |

## Conclusion & Rationale
The `all-MiniLM-L6-v2` model struggles with fine-grained domain-specific synonyms. It often assigns higher similarity to antonyms (e.g., Overfitting vs. Underfitting) than to genuine synonyms (e.g., Gradient Descent vs. Steepest Descent) because antonyms appear in very similar contexts.

**Decision:** We will keep the threshold at `0.75`. 
- Lowering it to `0.70` or `0.60` does not meaningfully improve F1 and introduces more false positives (e.g., Gradient Descent vs Backpropagation at `0.595`). 
- A threshold of `0.75` effectively captures nearly-identical lexical variations (like "Neural Network" and "Artificial Neural Network") while bounding the false positive rate. 
- A robust fix would require a domain-adapted embedding model or a cross-encoder rather than a generic lightweight dense retriever, but for the scope of this V1 pipeline, `0.75` is a defensible baseline.
